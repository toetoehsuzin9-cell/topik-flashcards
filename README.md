# TOPIK Korean–Myanmar Study Site

Flashcards, quizzes and a spaced-repetition "Memorize" mode for TOPIK vocabulary (3급–5급).

## Put it online with GitHub Pages
1. Create a GitHub account and click **New repository**. Name it `topik-flashcards`, set it to **Public**, click **Create repository**.
2. Click **uploading an existing file**, drag in `index.html`, `data.js` and `README.md`, then click **Commit changes**.
3. Open **Settings → Pages**. Under **Branch**, choose `main` and `/ (root)`, then click **Save**.
4. After 1–2 minutes your site is live at `https://YOUR-USERNAME.github.io/topik-flashcards/`.

## Adding words later
`data.js` holds every word as `[id, level, page, topic, korean, english, myanmar]`. Add new rows with a new unique id, commit, and the site updates.
Your progress is saved in each browser on your own device (not on GitHub).
